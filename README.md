# AI Exercise 1 — International Football Results Analysis

## Overview
This notebook analyzes the [Kaggle International Football Results dataset (1872–2024)](https://www.kaggle.com/datasets/martj42/international-football-results-from-1872-to-2017) as part of an Artificial Intelligence course exercise.

## Contents
| File | Description |
|---|---|
| `football_analysis.ipynb` | Main Jupyter Notebook with all analysis and visualizations |
| `results.csv` | Dataset downloaded from Kaggle (not included — download separately) |

## Topics Covered
- **Basic Exploration** — match count, date range, unique countries, most frequent home team
- **Goals Analysis** — average goals, highest scoring match, home vs away goals, most common scoreline
- **Match Results** — classifying outcomes (Home Win / Away Win / Draw), home advantage analysis, most wins by country
- **Visualization** — histogram of goals, bar chart of outcomes, top 10 teams by wins

## How to Run
1. Download `results.csv` from the Kaggle link above and place it in the same folder as the notebook.
2. Open `football_analysis.ipynb` in Jupyter Notebook or JupyterLab.
3. Run all cells (`Kernel → Restart & Run All`).
